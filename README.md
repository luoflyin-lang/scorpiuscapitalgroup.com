## 公司说明

Scorpius Capital Group LLC 是一家仅使用自有资金开展证券投资与资产配置的美国公司。

本公司不向公众募集资金，不接受客户委托，不提供投资顾问、经纪、托管或基金管理服务。公司股权为单一股东结构，投资决策、风险承担与资本安排均由公司内部完成。

## 网站用途

本网站用于展示公司的基础资料、内部公开级别的持仓口径、年度市场判断和财务披露目录，主要服务于品牌展示、档案留存和对外背景说明。

除特别说明外，网站内容均不构成：

1. 面向任何第三方的证券发行、销售或募集邀请。
2. 面向任何访客的投资建议、收益承诺或交易指令。
3. 对未来市场表现、流动性或估值结果的保证。

## 信息披露口径

1. 财务报表栏目展示的是公司层面的年度资料与披露说明，不涉及客户资产。
2. 持仓披露栏目用于说明公司的长期研究与资本配置偏好，不构成对外喊单。
3. 年度预测栏目记录公司对主要市场指数的年度判断，仅作为研究档案保存。
