# 持仓披露

本栏目用于展示公司对长期核心资产的研究偏好与资本配置取向。

## 披露说明

1. 本页面反映的是公司内部长期关注或长期持有方向，不构成对任何第三方的买卖建议。
2. 公司仅使用自有资金投资，因此持仓调整、增减仓节奏和风险承受均由公司自行决定。
3. 页面内容可根据研究结论、估值变化、流动性安排和风险控制需要进行更新。

## 配置原则

1. 优先考虑长期经营质量、现金流能力、资本回报和治理结构。
2. 允许在市场波动、估值变化和组合再平衡需求下对仓位进行调整。
3. 对于列入长期研究范围的资产，公司通常以多年维度评估，而非以短期行情驱动。

## 使用提示

访客不应将本栏目内容理解为收益承诺、托管说明、喊单信息或对未来价格的保证。
