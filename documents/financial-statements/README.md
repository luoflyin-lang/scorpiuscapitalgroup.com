# 财务报表

本栏目用于说明公司财务资料的披露范围与形成口径。

## 披露范围

1. 仅涉及 Scorpius Capital Group LLC 公司自身资产、负债、权益、损益和现金流情况。
2. 不涉及任何客户资金、代持资产、受托账户或基金份额。
3. 不展示与第三方账户安全相关的敏感数据。

## 形成原则

1. 财务数据以公司内部记账、券商对账单、银行流水和年度结账材料为基础整理。
2. 若未来公开年度报表，将以最终归档版本为准。
3. 如出现页面摘要与正式归档文件不一致的情况，以正式归档文件为准。

## 当前状态

当前栏目已完成结构预留，后续会按年度逐步补充可公开版本的公司财务资料与说明。
